# Robot_AI V5.1 HIL-Core Candidate

This package is deliberately built **from the Alpha.9 HIL-passed baseline**,
then carries forward only the V5.1 MissionManager/Return-Home improvements.

Use `PACKAGE_VALIDATION.txt` and `docs/V5_1_HIL_CORE_INTEGRATION.md` as the
package entry points.

Important: the Alpha.9 core was hardware-HIL validated, but the new V5.1
persistent HOME and Return Home behavior still requires a dedicated real-robot
HIL before this package can be called V5.1 HIL-PASSED.
