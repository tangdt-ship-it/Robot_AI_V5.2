# Tài liệu Robot_AI_V4.2

- `ARCHITECTURE.md` — phân tầng STM32/ESP32, fusion và quyền điều khiển.
- `HARDWARE_PINOUT.md` — pin hiện tại, gồm MPU6050 PC8/PB5.
- `CONTROL.md` — heading fusion, encoder odometry và motion control.
- `NAVIGATION.md` — odometry thật, breadcrumb và Return Home.
- `ROBOTLINK_V3.md` — UART/CRC và query IMU/FUSION/ODOMETRY.
- `SAFETY.md` — PS2, obstacle, encoder, watchdog và degraded mode.
- `V4_2_VALIDATION_CHECKLIST.md` — trình tự kiểm thử V4.2.

Source production và các tài liệu này là nguồn tham chiếu chính của V4.2.

- `V4_2_RELEASE_NOTES.md`: thay đổi V4.2, giới hạn và thứ tự commissioning.
