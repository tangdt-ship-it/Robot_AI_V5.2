# Tài liệu Robot_AI

## Tài liệu lõi

- `ARCHITECTURE.md` — phân tầng STM32/ESP32, fusion và quyền điều khiển.
- `HARDWARE_PINOUT.md` — pin phần cứng hiện tại.
- `CONTROL.md` — heading fusion, encoder odometry và motion control.
- `NAVIGATION.md` — odometry, breadcrumb và Return Home.
- `ROBOTLINK_V3.md` — RobotLink, telemetry và Alpha.3 `(SID, OP)` correlation.
- `SAFETY.md` — mô hình safety nền.
- `PROJECT_STATE.md` — lịch sử commissioning và trạng thái MAP/Replay kế thừa.

## V5 development

- `ROBOT_AI_V5_0_PROJECT.md` — phạm vi, safety invariants và các stage phát triển V5.
- `ROBOT_AI_V5_HIL_PLAN.md` — kế hoạch H0/H1/H2 cho Alpha.3.

## Tài liệu lịch sử

Các file V4.x được giữ nguyên tên để truy vết release, validation và commissioning; đây không phải tên repository hiện tại:

- `V4_2_RELEASE_NOTES.md`
- `V4_2_VALIDATION_CHECKLIST.md`
- `V4_3_TEST_REPORT.md`
- `V4_3_UPGRADE_REPORT.md`

Tương tự, các tên build environment và script có `v4_2` được giữ để đảm bảo compatibility.
